# Cloud Telegram

Cloud Telegram - это компактный backend-сервис на C++ с собственным HTTP API, многопоточностью, файловым хранилищем и отдельным клиентским приложением поверх этого API.

В основе проекта лежит C++ HTTP-сервер, который принимает файлы, сохраняет их на диск, объединяет в альбомы и по запросу возвращает их обратно. Отдельно от сервера работает Telegram-бот на Python. Он выступает клиентом backend-сервиса: принимает медиа из чата, отправляет его на сервер и позволяет просматривать сохранённые альбомы прямо в Telegram.

Проект задуман как цельное backend-приложение с понятным разделением ответственности. HTTP-слой, серверная логика, файловое хранилище и низкоуровневая инфраструктура разнесены по отдельным модулям, а внутри сервера используется fixed-size thread pool для параллельной обработки клиентских соединений.
